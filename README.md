## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080`.

## GitHub Pages

Enable Pages on the `main` branch (root). Site files are static HTML/CSS/JS.
